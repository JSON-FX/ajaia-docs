# Project brief

This file was uploaded as **Markdown** and converted to HTML on the server.

## Goals

- Ship a focused editor rather than a broad, shallow one
- Keep the permission model in a single auditable place
- Avoid infrastructure that adds no product value

## Non-goals

1. Real-time collaboration
2. Version history
3. Comments

> Scope discipline beats feature count.

Inline `code`, *italic*, and **bold** all survive the sanitizer's allowlist.

[A link](https://example.com) is preserved, but a `<script>` tag would not be.
